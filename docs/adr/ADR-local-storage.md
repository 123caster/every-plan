# ADR：本地存储与迁移

- 状态：已接受
- 日期：2026-10-03

## 决策

以 IndexedDB 为本地事实源，通过 `idb` 提供 Promise API。Schema 当前为 v2：

- `tasks`：任务实体，带 `updatedAt` 索引。
- `preferences`：设备级主题、密度、字号、详情方式和动态效果。
- `meta`：Schema 与后续迁移元数据。

所有仓库通过适配器访问数据库，React 组件不能直接使用 IndexedDB API。

## 迁移策略

升级前先执行可失败的预检；预检失败时不打开升级事务，旧库保持原版本并向上报告错误。进入 IndexedDB `versionchange` 后，迁移依靠浏览器事务的原子性。测试覆盖首次建库、关闭重开、v1 到 v2 数据保留，以及预检失败后旧数据仍可读取。

## 后果

真实云同步接入后，IndexedDB 仍作为离线实体库；同步层只能通过仓库接口合并版本，不得绕过迁移和写入约束。
