# ADR：周日历渲染与拖动

- 状态：P0 接受
- 日期：2026-10-03

## 决策

P0 使用平台自有的语义化 CSS Grid 周视图，不引入完整日历组件库。每个日期列最小宽度为 `10.5rem`，容器在空间不足时横向滚动；字号放大到 130% 时列宽随根字号增长，不压缩任务标题。

交互采用两条等价路径：

- 指针按下并移动到目标日期列后松开。
- 聚焦任务后使用左右键移动日期、上下键移动开始时间。

时长通过明确按钮调整，后续正式日历可以在同一命令层增加拖拽手柄。

## 证据与修正

真实 Edge 验证发现，HTML5 `dragstart/drop` 在当前 Playwright 场景没有产生事件，因此没有把不稳定的 `dataTransfer` 方案保留下来。最终使用 Pointer Events，并在测试中先把横向滚动目标带入视口，再执行真实鼠标移动。这同时暴露并验证了 130% 字号下的横向滚动边界。

## 后果

如果后续任务重叠、吸附和跨资源列复杂度上升，可仅替换拖拽底层；视图语义、命令和键盘操作不随库迁移。
