# ADR：前端状态、查询缓存与表单

- 状态：已接受
- 日期：2026-10-03

## 决策

- Zustand 5：客户端实体索引和 UI 状态。
- TanStack Query 5：未来服务端查询缓存与实体快照入口。
- React Hook Form 7：任务编辑和导入映射表单。

P0 切片证明了创建任务、修改计划/截止时间、撤销未提交修改、保存到本地仓库，以及模拟服务端快照合并。设备主题和布局偏好不放进服务端查询缓存，因此实体刷新不会覆盖 UI 偏好。

## 原因

这三层职责边界清晰：Zustand 不负责远端请求生命周期，TanStack Query 不承担临时表单，React Hook Form 不保存领域实体。它们都能单独注入或替换，适合本地优先和未来模块化拆分。

## 未选择

- 纯 React Context：小页面可用，但实体更新和测试隔离会迅速变重。
- Redux Toolkit：能力完整，但当前个人应用 Demo 的样板和包体积收益不够。
- 把所有数据放进 TanStack Query：会把本地设备偏好与未来服务端状态混为一层。
