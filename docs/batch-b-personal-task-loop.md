# 批次 B：个人任务最小闭环

- 状态：已实现并验证
- 日期：2026-10-03
- 范围：Today、Quick Create、Task Detail、本地持久化

## 已实现

1. `/today` 今日工作台，展示日期、待办数、预计总时长、完成进度，以及“接下来 / 稍后 / 已完成”分组。
2. 全局 `Ctrl/Cmd + K` 和桌面/移动端创建入口。
3. 确定性快速语法：`今天 14:30`、`明天 09:00`、明确日期时间、`#标签`、`!高/中/低`、`/45m`、`/2h`。歧义自然语言保留在标题中。
4. 快速创建支持“创建任务 / 创建并打开 / 创建并继续”，标准字段始终可编辑。
5. 任务详情通过 `?task=<id>` 恢复；支持抽屉、中央窗口、移动端全屏、自动保存、子任务、备注和插件扩展区。
6. IndexedDB 任务仓库支持 CRUD、完成/重新打开、移动计划、事务写入和命令幂等。
7. 计划、截止、预计时长分别建模，任务投影按时区去重。

## 明确边界

- `/plugins` 和 `/plugins/import` 只提供已标记的后续入口，不模拟真实安装成功。
- 周日历仍使用批次 A 的技术验证页；正式日历页面属于批次 C。
- 没有账号、云同步、通知、重复规则引擎和真实插件运行时。
